2026.01 — 2026.08

智能汽车竞赛室内赛（竞速组）
主控与电机驱动硬件设计Indoor Intelligent Car Competition · Main Controller & Motor Drive Hardware

国家级二等奖 National Second Prize

面向室内赛雁过留痕组，设计智能车主控板与双路电机驱动板，完成车载电源、传感器接口和底盘驱动硬件支撑。Designed the main control board and dual-channel motor driver for an indoor competition vehicle, providing onboard power, sensor interfaces and chassis drive hardware.

核心工作 Key contributions

  1. 基于 TPS5430DDAR 搭建舵机与系统 5V Buck 电源，用 LDO线性稳压器 输出 3.3V 电源，通过 功率电子开关SY6280AAC 控制 5V 外设电源使能。Built a 5V Buck supply for the servo and system with the TPS5430DDAR, generated 3.3V with an LDO linear regulator, and used the SY6280AAC power switch to control the 5V supply to peripherals.
  2. 围绕 STC32G144K246 核心板设计接口，集成摄像头、编码器、舵机、激光、屏幕、无线 SPI、姿态传感器和蜂鸣器。Designed interfaces around the STC32G144K246 core board for the camera, encoders, servo, laser, display, wireless SPI, inertial sensor and buzzer.
  3. 采用 DRV8701ERGER 栅极驱动器与 TPH1R403NL MOSFET 搭建双路分立 H 桥，加入 SN74HC125PWR 输入缓冲、nSLEEP 休眠控制及保护电路，实现正反转与 PWM 调速。Built two discrete H-bridges with DRV8701ERGER gate drivers and TPH1R403NL MOSFETs; added SN74HC125PWR input buffering, nSLEEP control and protection circuitry for bidirectional motor operation and PWM speed control.

省级一等奖 Provincial First Prize

制作搭载视觉追踪云台的智能小车。Built an intelligent vehicle with a vision-tracking pan-tilt unit.负责视觉识别、主控通信与赛后云台结构和算法优化。Worked on visual recognition, controller communication and post-competition improvements to the mechanism and vision algorithm.

30 → 46 FPS

优化视觉算法后的识别帧率Vision recognition frame rate after optimization

核心工作 Key contributions

  1. 使用 K230 识别矩形靶，与 MSPM0G3507 主控通过串口通信，使小车行进时动态追踪矩形靶，并发射蓝紫色激光至 UV 感光纸。Used the K230 to detect a rectangular target and communicated with the MSPM0G3507 controller over a serial link, enabling the moving vehicle to track the target and project a blue-violet laser onto UV-sensitive paper.
  2. 赛后独立完成步进电机云台的 3D 建模与打印，优化结构和视觉算法，将识别帧率从 30 帧提升至 46 帧，并开源云台设计。After the competition, independently modeled and 3D-printed a stepper-motor pan-tilt unit, improved its structure and vision algorithm, raised recognition speed from 30 to 46 FPS, and open-sourced the design.

2025.09 — 2025.12

智能汽车竞赛室外赛
ROS 组自主行驶系统Outdoor Intelligent Car Competition · ROS Autonomous Driving System

省级三等奖 Provincial Third Prize

开发融合激光雷达、工业摄像头与编码器的智能行驶车，实现锥桶赛道自主行驶。Developed an intelligent vehicle combining LiDAR, an industrial camera and encoders to navigate a cone-marked course autonomously.

激光雷达LiDAR · Point clouds视觉识别Vision · YOLOv5ROS 节点ROS nodes · Messaging底盘控制Chassis · Driving

核心工作 Key contributions

  1. 将单体程序拆分为雷达处理、视觉识别、小车控制等独立 ROS Node，通过 launch 脚本一键启动硬件驱动与算法节点。Split a monolithic program into separate ROS nodes for LiDAR processing, visual recognition and vehicle control, then used a launch script to start hardware drivers and algorithm nodes together.
  2. 使用 Topic 通信与 mutex 互斥锁同步 YOLO 识别数据和底盘控制节点；通过 Service 通信保存行驶过程中 SLAM 构建的栅格地图。Used ROS topics and a mutex to synchronize YOLO detection data with chassis control; used a ROS service to save the SLAM occupancy grid during driving.
  3. 将锥桶雷达点云数据处理从 k-means 聚类改为 DBSCAN 聚类，无需预设聚类数量即可自动聚类。Replaced k-means with DBSCAN for cone LiDAR point-cloud clustering, removing the need to specify the number of clusters in advance.
