# 晏陆君 · HTML 简历

直接在浏览器中打开 `index.html` 即可查看，无需安装依赖或构建。页面采用中文原句、英文译句相邻的双语排版，以及剪报、牛皮纸、贴纸和网点印刷的拼贴视觉。滚动时纸片弹性入场、封面图形分层移动，顶部红色印刷线标示阅读进度；系统设置为“减少动态效果”时会自动停用这些动画。

支持桌面和手机宽度、原理图放大查看，并提供原版中文 PDF 下载和打印样式。

内容依据 `../latex/yanlujun_resume.tex` 整理；证件照、项目实物照片、PCB 图、电路原理图、云台动图、中英文采访视频和 PDF 副本均存放在 `assets/`，因此复制整个 `html_resume` 文件夹后仍可独立使用。采访视频仅在点击播放后加载，原文件约 330 MB。
